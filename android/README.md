# Android 客户端

Kotlin / Jetpack Compose 客户端，与 CLI 共用 Go 核心，支持 TCP / UDP 映射、房间语音和网络诊断。
手机包需要 Android 8.0+（API 26）及 ARM64；手表请使用 [Wear OS 版本](wear/README.md)。

## 使用

1. 在“设置 → 房间与身份”填写服务器、信令密码、房间号、房间口令和设备名；两端设备名应不同。
2. 在“服务”添加提供或使用服务，与另一端使用相同服务 ID，并启用条目。
3. 点击首页播放按钮启动，在“连接”查看线路和本地访问端口；点击暂停按钮停止。

加入房间、设备连通与服务可用是独立状态。访问失败时，先查看对应设备和映射的详情。

普通连接使用 ICE，支持 IPv4 / IPv6 直连及中继。在“设置 → 连接方式”可调整 STUN、TURN、Hole 中继设备和尝试顺序。
“通过房间设备接收信令”表示当前使用组内其他设备转发通知，已有数据连接可继续运行。

### 应用内更新

在“设置 → 检查更新”获取 GitHub 最新正式发行版，下载后由 Android 安装程序确认安装。
可选择直连、预设加速线路或自定义 HTTPS 前缀；支持查看进度、取消、重试及同版本重新下载。

下载由系统在后台继续，重新进入更新页可查看任务。手机与 Wear 分别选择对应 APK，缺少 Wear 包时不会用手机包代替。

## 连接与诊断

| 入口 | 用途 |
| --- | --- |
| 设备详情 | 查看路径、实际地址、NAT、端口映射、中继和连接错误 |
| NAT 检测 | 无需加入房间，支持开始、取消、重新检测及导出报告 |
| 打洞过程 | 查看连接阶段、双端端口计划、报文和 NAT 采样；支持筛选、暂停与回放 |
| 导出完整记录 | 在打洞过程页通过系统文件选择器保存核心当前保留的全部记录 |

NAT 类型与可预测性是当前网络的观测结果，不保证直连成功。自动 UDP 端口映射和分类 STUN 可在连接设置中调整。

QUIC 统计显示合计、上行、下行的丢包率、峰值速率和平均速率；无样本与缺少对端反馈分别标注。
连接重试、本机丢弃与网络丢包分别统计，速率表示当前使用量。详细口径见 [协议统计说明](../docs/PROTOCOL.md#重连与状态展示)。

固定入口通道显示公布入口、监听方、拨号方和实际地址，失败后仅重试固定路径。
固定入口监听和 Hole 中继服务需通过 CLI 配置；Android 可连接这些设备，连接方式页支持 Hole / UDP / TCP / TLS 排序。
TURN 关闭后仍可使用 Hole 中继。

## 界面与外观

底部导航提供首页、服务、连接、语音和设置。服务支持编辑、启用、停用、删除和撤销；连接支持搜索、筛选及详情查看。

外观支持浅色、深色、跟随系统、五种强调色，以及 Android 12+ 动态配色，动画遵循系统时长设置。

### 悬浮球与后台运行

在“设置 → 后台运行”开启悬浮球并授予“显示在其他应用上层”权限。
悬浮球可拖动并记住位置，点按查看线路、会话和流量，也可启停转发或打开详情；大小可设为 32–96 dp，默认 48 dp。

转发和悬浮球使用前台服务及运行通知。划掉最近任务后仍可继续运行；强制停止或系统清理可能中断服务。
重新打开应用可恢复已开启的悬浮球，开机时不会自动显示。

## 房间语音

两端加入同一房间并启用语音，无需添加服务映射，最多支持 8 台语音设备。

语音页可静音、选择自动 / 手机 / 耳机麦克风，并查看实际采集与输出设备、媒体收发和音频错误。
自动模式优先使用可用的耳机麦克风；输出随通信耳机插拔切换，没有耳机时使用扬声器。
回声消除和降噪按设备支持情况启用，页面显示结果。关闭语音后端口转发继续运行。

## 配置交换

支持导入导出 CLI YAML / JSON，也可粘贴配置或应用备份后预览导入。
完整备份包含停用条目和界面设置，默认导出不含凭据；本机凭据由 Android Keystore 保护。

从旧版升级时，保存配置和备份中的旧连接模式及手动 IPv6 候选会被清理，房间身份、凭据、服务和 TURN 设置保留。
共享核心 1.1.0 使用统一 ALPN `hole`，参与连接的核心需同步升级。

## 构建

在仓库根目录配置现有签名信息后执行：

```bash
cp -n signing.env.example signing.env
# 填写已有密钥库的信息
./build.sh android
```

产物位于 `dist/android/`，包含 `hole-<version>-release.apk`、R8 mapping、构建清单和校验和。
构建自动生成 Go AAR；工具链和签名要求见 [构建指南](../docs/BUILDING.md)。

模块分为手机 `app`、手表 `wear` 和网络桥接 `corebridge`。
接入接口见 [mobile API](../mobile/README.md)，共用界面的桌面版本见 [Kotlin 桌面端](../desktop/compose/README.md)。
