# Wear OS 客户端

独立运行的手表应用，支持 TCP / UDP 映射、房间语音、NAT 诊断和配置交换，不依赖手机配对。
功能和配置与 [Android 客户端](../README.md) 共用。

[圆屏操作](#圆屏操作) · [安装与更新](#安装与更新) · [构建](#构建) · [项目首页](../../README.md)

## 设备要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Android API 26+，具备手表设备特性 |
| ABI | `armeabi-v7a` 或 `arm64-v8a` |
| 包名 | `dev.hole.app` |
| 安装包 | `hole-<版本>-wear-release.apk` |

部分手表使用 32 位 Android 用户空间，因此 Wear 包同时包含两种 ARM ABI。手机请使用手机版 APK。

## 圆屏操作

- 底部白色弧条可点按或上拉展开导航，下拉、点按弧条或系统返回可收起。
- 旋转表冠滚动页面、表单和弹窗；导航展开时可横向浏览导航项。
- 主页面提供首页、服务、连接、语音和设置；首页可启动或停止转发。
- 表单保存 / 删除按钮位于内容末尾，长内容支持触摸和表冠滚动。
- 中继顺序使用上移 / 下移按钮，也可启用、停用类型或恢复默认。
- 服务编辑、删除撤销、配置导入、外观、后台运行和语音操作沿用手机端功能。

## 安装与更新

下载 Wear APK，由手表的系统安装程序确认安装。已有安装需使用相同签名且符合版本升级要求。

应用内打开“设置 → 检查更新”，支持与手机相同的下载线路、进度、取消、恢复和同版本重新下载。
更新器只选择手表包；发行版缺少 Wear APK 时会提示，不会改用手机包。

首次安装更新可能需要允许 Hole 安装未知应用。固件缺少安装权限页或 APK 安装程序时，可使用 ADB：

```bash
adb -s SERIAL install -r hole-<版本>-wear-release.apk
```

安装失败时查看 `INSTALL_FAILED_*` 错误，并核对系统版本、ABI、签名和版本号。

## 构建

在仓库根目录执行，签名配置与手机版共用：

```bash
./build.sh wear --signing-config signing.env
```

产物位于 `dist/wear/`，包含双 ARM ABI 的 Release APK、R8 mapping、构建清单和校验和。
手机与手表共用 `versions.json` 中的 Android 前端版本和 `versionCode`。
工具链及签名配置见 [构建指南](../../docs/BUILDING.md)。
